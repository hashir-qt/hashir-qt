### What I build
- **Multi-tenant platforms** with clean data isolation
- **Agentic systems** that orchestrate multiple AI agents with human approval gates
- **RAG pipelines** that answer from a company's own data
- **MCP connectors** that give AI tools new abilities

### Projects
- **Quinn:** Multi-tenant AI commerce platform that runs sales, support and operations for e-commerce brands over WhatsApp. Grew out of an agent handling ~30K conversations a month for one brand
- **EasyOrder:** AI food ordering agent on WhatsApp for a multi-restaurant marketplace in Karachi. Takes customers from area to menu to cart to confirmed order
- **ReelVision:** MCP connector that lets Claude and ChatGPT watch reels from a link. Live at [reels.hashirfiles.com](https://reels.hashirfiles.com)
- **AI HR Platform:** Five agents built on the Claude Agent SDK, FastAPI and Next.js, with a human approval step before anything ships
- **UBIT Portal:** University portal web app for UBIT, University of Karachi
